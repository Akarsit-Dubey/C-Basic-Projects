# 🪨📄✂️ Rock Paper Scissor Game

## Description
A 2-player console game written in C.  
Both Player 1 and Player 2 enter their moves using numeric choices, and the program evaluates the winner based on standard Rock-Paper-Scissors rules using `if-else` logic.

## Game Rules
- **Rock vs Scissor** → Rock wins (Player with Rock wins)  
- **Paper vs Rock** → Paper wins (Player with Paper wins)  
- **Scissor vs Paper** → Scissor wins (Player with Scissor wins)  
- **Same choice** → It's a Tie!

## Choices Menu
- **1** → Rock  
- **2** → Paper  
- **3** → Scissor  

## Example
```
Player 1, Choose (1: Rock 2: Paper 3: Scissor) : 1
Player 2, Choose (1: Rock 2: Paper 3: Scissor) : 3
Player 1 Wins!!
Yayy!!
```
