# 🎓 Grade Check Program

## Description
This C program evaluates a student's marks and determines whether they have **passed or failed** the examination.  
If passed, it assigns a grade (A+ to D) based on the marks obtained. If failed, it assigns grade **F**.

## Grading Criteria
- **90–100** → Grade A+  
- **75–89** → Grade A  
- **60–74** → Grade B  
- **40–59** → Grade C  
- **33–39** → Grade D  
- **Below 33** → Fail (Grade F)

  
## ▶️ How to Compile & Run
```bash
gcc grade-check.c
./grade-check
